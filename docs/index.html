Temporal Heterogeneous Biomedical Knowledge Graph

What was known,
and when.

THBKG is a biomedical knowledge graph in which every edge carries the year its evidence first appeared. Cut it at any date and you get the graph as a drug-discovery team would have seen it then — which makes it possible to benchmark target prioritisation without leaking the future.

§ 01

The graph, as of a decision year

Static knowledge graphs answer questions with everything known today. For predicting which drug targets will succeed, that is a leak: the evidence that made a target famous often arrived after the decision you are trying to model. THBKG dates every evidence edge, so a model scoring a 2016 decision only ever sees edges dated before 2016.

    § 02

    What's in the 26.09 release

    Five node types — targets, diseases, molecules, Gene Ontology terms and Reactome pathways — joined by sixteen dated relations and three static hierarchies. Sources: Open Targets 26.09, Gene Ontology, Reactome, IntAct, the Human Protein Atlas and ClinicalTrials.gov, each pinned to a recorded version.

    Clinical-trial edges are dated by outcome: a trial adds an ongoing edge when it starts and, once finished, an outcome edge (positive, unmet efficacy, adverse effects or unknown) at its actual completion date.

    § 03

    The advancement benchmark

    Each example is a target–disease pair that entered Phase II. The task is to rank pairs by how likely they are to reach Phase III, using only evidence dated strictly before the pair's Phase II year. Labels follow a fixed horizon (the protocol of Czech et al.): a pair is positive if it reached Phase III by 2018 (train) or 2024 (eval).

    The primary metric is Relative Success @ K, an importance-weighted hit rate, reported per therapeutic area (13 areas) and Wilcoxon-tested against a randomized-decisions baseline. Labels are kept outside the graph and joined by node ID, so supervision never enters message passing.

    § 04

    Quick start

    The Hugging Face release is pickle-free (safetensors + parquet) and ships a standalone loader.

    from huggingface_hub import snapshot_download
from load_thbkg import load_graph, load_labels, node_index  # shipped with the dataset

path  = snapshot_download("jspc00012567/THBKG", repo_type="dataset")
graph = load_graph(path)            # PyG HeteroData, training view
train = load_labels(path, "train")  # target_id, disease_id, transition_year, outcome
evals = load_labels(path, "eval")

# the graph as of a decision year: keep edges dated strictly before it
year = 2016
for et in graph.edge_types:
    if "edge_time" in graph[et]:
        keep = graph[et].edge_time < year
        graph[et].edge_index = graph[et].edge_index[:, keep]

    To rebuild from source or train the reference models, see the repository README.
